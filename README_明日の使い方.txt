訪問GPSメモ v0.1 — iPhone用・単体GPSレコーダー
===============================================

【最初に読んでください】
これはWebアプリ（PWA）です。iPhoneの画面をロックした状態や、
Safariがバックグラウンドになった状態での連続記録は保証できません。
明日の走行経路を確実に残すには、バックグラウンドGPSに対応する
既存の専用アプリを併用してください。

【iPhoneでの設置】
1. このZIPをNetlify Dropにアップロード
   https://app.netlify.com/drop
2. 発行された https://xxxx.netlify.app をiPhoneのSafariで開く
3. 位置情報「このWebサイトの使用中」＋「正確な位置情報」を許可
4. よければ共有ボタンから「ホーム画面に追加」
5. 家の周りで1〜2分試す（可能なら歩行テスト）

【明日の操作】
1. 出発前に「記録開始」。Safariを手前に開いたままにする
2. 訪問先では車を停めてから「＋ここを訪問先として保存」
   GPSが不正確な場合は、表示される位置誤差を確認する
3. 訪問番号をメモして、お客様リストとあとで照合できるようにする
   顧客氏名・住所など個人情報をアプリ内メモへ入力しない
4. 途中でSafariを離れると記録が一時停止するので「記録再開」
5. 終了後は「GPXを書き出す」と「JSONをバックアップ」の両方を保存
6. 出力したGPXをChatGPTへ添付すれば走行経路や停車候補を分析可能
   ※訪問先GPSと顧客情報は機微な業務情報。許可された範囲で管理する

【できること】
- GPS移動経路の取得（Safari前面での利用）
- 訪問先ごとにワンタップでピン保存、番号自動付与
- 距離・GPS誤差・日時表示
- GPX / 訪問一覧CSV / 再読込可能なJSONバックアップ
- 端末内自動保存（IndexedDB）、複数日・複数記録の管理
- 個人情報を外部に送信しない。背景地図タイルのみ外部取得

【注意】
- GPSは建物・トンネル・山間部で数十m以上ずれることがあります
- ブラウザ内データは端末のストレージ消去等で失われ得ます
- 保存データは暗号化していません。顧客名などは入力しないでください
- Netlify URLが変わると保存領域が別になりデータは引き継がれません
- NetlifyへのアップロードにGPSファイルは入っていません
- 運転者は操作せず、助手席で操作するか安全に停車してから操作する

技術構成：静的HTML / JavaScript / Leaflet / IndexedDB
地図：OpenStreetMap / Leaflet (ライセンスはvendor内)
